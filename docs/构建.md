# 从源码构建

## 依赖

- Python 3.9或更新版本。
- CMake 3.18或更新版本、Ninja。
- Arm GNU Toolchain，编译器`arm-none-eabi-gcc`位于PATH中，或设置`PICO_TOOLCHAIN_PATH`为工具链根目录。
- Pico SDK 2.1.1及其TinyUSB子模块。

在项目根目录准备SDK：

```powershell
git clone --depth 1 --branch 2.1.1 https://github.com/raspberrypi/pico-sdk.git .deps/pico-sdk
git -C .deps/pico-sdk submodule update --init --depth 1 lib/tinyusb
```

## Windows

```powershell
.\scripts\build.ps1 -PicoSdkPath .deps/pico-sdk
```

## Linux / macOS

```bash
export PICO_SDK_PATH="$PWD/.deps/pico-sdk"
bash scripts/build.sh
```

固件输出为 `build/pico/pico_ocarina.uf2`。工程使用内置脚本打包RP2040 UF2。

内置默认曲来自 [auld_lang_syne_playback.json](../songs/auld_lang_syne_playback.json)。换歌可直接上传JSON；修改内置默认曲时替换该文件并重新构建。

## 桌面校验工具

需要C++17编译器、CMake和Ninja：

```powershell
cmake -S . -B build/tools -G Ninja -DOCARINA_HOST_TOOLS=ON
cmake --build build/tools
./build/tools/melody_check songs/auld_lang_syne_playback.json
```

`melody_check`读取歌曲JSON，输出音数、总时长和倒数；加`--events`可列出音符与对应输入状态。

GitHub Actions在`main`、`prod`和`prod-multi-lang`分支构建固件和桌面校验工具。构建完成后可在Actions页面下载UF2及校验值。英语和日语翻译可通过 `python tools/check_locales.py` 检查。
