# 使い方

[English](GettingStarted.md) · [简体中文](../开始使用.md) · **日本語**

## ファームウェアの書き込み

通常のRaspberry Pi Pico（RP2040）とUSBデータケーブルを使います。

1. BOOTSELを押しながらPicoをPCにつなぎます。
2. RPI-RP2ドライブに[Pico_Ocarina.uf2](../firmware/Pico_Ocarina.uf2)をコピーします。
3. Picoが自動で再起動すれば完了です。[SHA256SUMS.txt](../firmware/SHA256SUMS.txt)でファイルを照合できます。

## Switchで再生

1. PicoをSwitchのUSB端子につなぎ、ゲームのオカリナ演奏画面を開きます。
2. 有線コントローラーの認識が必要な場合、待機中にBOOTSELを約1秒長押しします。L+Rを0.5秒、1秒離す、もう一度L+Rを0.5秒、1秒離す、Aを0.5秒の順で送信します。
3. BOOTSELの短押しで再生し、もう一度押すと停止します。認識操作の途中でも、再度押すと中止できます。

内蔵曲は「蛍の光（Auld Lang Syne）」で、開始待ちは3秒です。LEDは接続待ちでゆっくり点滅、待機中は点灯、開始待ちでは速い点滅、再生中は中程度の点滅になります。

## 管理アプリを開く

Tcl/Tk付きのPython 3.9以降をインストールし、[Launch.cmd](../Launch.cmd)または[PicoOcarina.pyw](../PicoOcarina.pyw)を開いてください。必要な部品はアプリから、または次のコマンドでインストールできます。

```powershell
python -m pip install -r tools/requirements-gui.txt
```

上部の言語欄で**日本語・English・简体中文**を選べます。切り替えても読み込んだ曲や変換設定は保持され、次回の起動にも選択が保存されます。

## 曲を転送

1. Picoの電源を外し、**GP21とGND**をジャンパーでつないでからPCに接続します。
2. 「JSONを読み込む…」で曲を選ぶか、「MIDIを開く…」でMIDIを変換します。
3. 「Picoに転送」でポートを更新して選択し、「現在の曲をPicoに転送」を押します。
4. 保存の確認が終わったら電源を外し、GP21のジャンパーを抜いてSwitchにつなぎます。

保存した曲は内蔵曲より優先されます。ファームウェアを書き直しても保存曲は残ります。内蔵曲に戻す場合は[既定の曲JSON](../songs/auld_lang_syne_playback.json)を読み込み、再転送してください。

コマンドからの転送と確認：

```powershell
python tools/upload_melody.py song.json --port COM5
python tools/upload_melody.py --port COM5 --status
```

## MIDIを変換

1. MIDIを開き、主旋律のトラックとチャンネルを選んで試聴します。
2. 和音がある場合は「最高音を選ぶ」または「最低音を選ぶ」を指定します。
3. 「範囲を選ぶ…」で、左右の青い線を動かして時間を選び、緑の枠を上下に動かして音域を選びます。枠の幅は18半音です。
4. 「この範囲を使う」を押し、曲名、移調、速度、開始待ちを調整して「曲を書き出す」を押します。
5. 結果を試聴してからPicoに転送します。

時間範囲を変えると、最多の音を含む音域枠を自動選択します。枠外の音は除外されます。演奏可能な音高はMIDI 71–89（B4–F6）で、音の間隔は既定で120msです。詳細は[MIDI変換と曲の形式（英語）](MIDIConversion.md)をご覧ください。

## 配線

| Picoの端子 | 接続 |
|---|---|
| GP21 | GNDにつないでから電源を入れると設定モード |
| GP22 | 任意の外付けボタン。もう一方をGNDへ |
| GP25 | 基板上のLED |
| BOOTSEL | 基板上のボタン |

## よくある質問

**ウィンドウが開かない：** Tcl/Tk付きのPython 3.9以降を使い、`tools/requirements-gui.txt`をインストールしてください。

**ポートが見つからない：** GP21をGNDにつないで電源を入れ直し、データケーブルを使ってください。他のアプリがポートを使っていれば閉じてから更新します。

**書き直したのに前の曲が鳴る：** 保存曲が優先されます。再生したいJSONを転送してください。

**音域や複数音のエラー：** 音域枠、選音、移調を調整して試聴してください。複雑な編曲では、先に主旋律を単音MIDIとして抽出してから読み込めます。
